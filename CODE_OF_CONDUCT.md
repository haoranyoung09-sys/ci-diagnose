# Code of Conduct

CI Doctor adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. The full text, including the enforcement ladder, is at that link.

## Short version

We want this project to be a welcoming, harassment-free place for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

In practice:

- Be respectful. Disagree about the code, the taxonomy, or a fixture, and leave people alone.
- Assume good faith. Ask before you assume malice.
- Give feedback that is specific, and accept it the same way.
- Do not insult, harass, troll, or publish someone's private information.
- Do not sexualize the space or make unwelcome advances.

## Scope

This code applies in issues, pull requests, discussions, and any other project space. It also applies when someone is representing the project in public.
