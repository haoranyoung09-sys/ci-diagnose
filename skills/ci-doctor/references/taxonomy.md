# Taxonomy v0 (skill reference)

Ids: `flake`, `env`, `test`, `deps`, `permissions`, `infra`, `unknown`.

The CLI in `scripts/diagnose.py` is the smoke oracle. It scores the signals below, picks the leader when the score is at least 6, and returns `unknown` under that threshold or on a tie. If you edit a signal here, edit the rule and [docs/taxonomy.md](../../../docs/taxonomy.md) in the same change. When the full repo is not on disk, this file is enough to classify by hand.

Confidence from the CLI: `high` (≥ 0.80), `medium` (≥ 0.60), `low`. Repeat that level. Do not round it up to a merge decision.

| id | Pick it when | Do not pick it when | Fixture |
| --- | --- | --- | --- |
| `flake` | Timeout, "timeout of N ms exceeded", "suspected flake", passed on rerun, intermittent, retry N of M, checkout TLS / certificate verification failure, external dataset or host timeout (including a chronic host), a hook that failed because checkout failed, service or Helm health check timeout | The assertion fails the same way every time, or it ties with `AssertionError`. A shard that only says "retry N of M" is under the threshold. A hook with no checkout line is under the threshold. A registry `no such host` or `egress blocked` line is `infra`. A chronic host is still `flake`; do not rerun the same URL twice | `jest-timeout-flake`, `registry-timeout-rerun-flake`, `playwright-timeout-flake`, `cypress-timeout-flake`, `matrix-shard-flake`, `docker-rate-limit-flake`, `checkout-tls-verify-flake`, `external-dataset-host-flake`, `checkout-tls-hook-cascade-flake`, `service-healthcheck-timeout-flake`, `helm-healthcheck-timeout-flake`, `external-host-chronic-flake`, `docker-pull-rate-limit-flake`, `cypress-retry-timeout-flake`, `git-lfs-rate-limit-flake`, `cargo-registry-network-flake`, `terraform-state-lock-flake`, `kubectl-rollout-timeout-flake`, `github-secondary-rate-limit-flake`, `go-proxy-502-flake`, `econnreset-flake` |
| `env` | A named variable, action input, or secret name is unset or empty, including a Compose `DATABASE_URL` | The token is present and GitHub returned 403, or the empty name ties with "does not have permission" | `missing-database-url`, `missing-node-auth-token`, `unset-api-base-url`, `secret-signing-key-missing`, `aws-region-undefined`, `compose-db-url-unset`, `node-engine-mismatch-env`, `setup-python-version-missing-env`, `composite-action-path-missing-env`, `terraform-credentials-missing-env`, `app-store-connect-key-missing-env`, `apt-pubkey-missing-env`, `gcp-adc-missing-env`, `composer-php-platform-env`, `workflow-secret-not-passed-env` |
| `test` | `FAIL` / `FAILED`, `--- FAIL:`, `AssertionError`, PHPUnit "Failed asserting that", RSpec `Failure/Error:`, cargo `test result: FAILED`, Gradle `AssertionError` | The suite never started, a timeout that passed on rerun, a hook that failed only because checkout failed, or a tie with that timeout or with a lockfile. In a multi-job log, ignore signals that appear only on a green job | `npm-test-assertion`, `pytest-assertion`, `go-test-want-got`, `maven-surefire-assertion`, `phpunit-assert-failed`, `rspec-failure-error`, `cargo-test-result-failed`, `gradle-test-assertion`, `multi-job-one-step-failed`, `cargo-type-mismatch-test` |
| `deps` | `ERESOLVE`, peer conflict, npm, pnpm, yarn, poetry, uv, Bundler, Cargo, or go.sum drift, pip unsatisfied, Gradle unresolved configuration | `NODE_AUTH_TOKEN` is simply empty, the lockfile ties with `AssertionError`, cache `EACCES` tied with a lockfile, or a corrupt `actions/cache` restore that outranks the lockfile | `npm-peer-eresolve`, `npm-ci-lockfile-drift`, `pnpm-outdated-lockfile`, `pip-version-unsatisfied`, `yarn-lockfile-out-of-date`, `poetry-lock-out-of-date`, `uv-lock-needs-update`, `gradle-configuration-unresolved`, `bundler-lockfile-out-of-date`, `go-sum-checksum-mismatch`, `cargo-lock-needs-update`, `pnpm-lock-not-up-to-date-deps`, `continue-on-error-lockfile-deps`, `maven-dependencies-unresolved-deps`, `swiftpm-package-unresolved-deps`, `cocoapods-pod-conflict-deps`, `nuget-package-not-found-deps`, `deno-lockfile-out-of-date-deps`, `nix-flake-output-missing-deps` |
| `permissions` | Integration 403, `HttpError` 403, `permissions:` or `id-token:` not granted, remote rejected the push, OIDC assume-role blocked on `id-token: write`, `pull access denied`, `unauthorized: authentication required` | A secret value was never provided, a filesystem `EACCES`, only "Refusing to force-push", an empty role ARN tied with "does not have permission", or registry auth tied with `egress blocked` | `gha-token-integration-403`, `git-push-permission-denied`, `id-token-permission-denied`, `bare-http-403`, `oidc-assume-role-denied`, `registry-pull-auth-denied`, `github-bad-credentials-permissions`, `kubectl-rbac-forbidden-permissions`, `aws-invalid-token-permissions` |
| `infra` | Heap OOM, generic "out of memory", disk full, runner killed, Docker daemon unreachable, Docker build disk full, registry/MCR pull blocked (`no such host`, `egress blocked`, TLS handshake timeout, `i/o timeout`), DNS (`getaddrinfo`, "Temporary failure in name resolution"), `Failed to restore cache` | A flaky timeout that passed on rerun, checkout certificate verification (`flake`), `pull access denied` with no egress line (`permissions`), bare `EACCES` on a cache directory, or OOM, egress, or cache `EACCES` tied with a permission or lockfile line | `node-heap-oom`, `runner-disk-full`, `generic-oom-without-heap`, `runner-killed-exit-137`, `docker-build-disk-full`, `docker-daemon-unavailable`, `mcr-pull-egress-blocked`, `ghcr-pull-io-timeout`, `dns-name-resolution-infra`, `actions-cache-restore-corrupt`, `kernel-oom-killed-infra`, `self-hosted-runner-offline-infra`, `windows-filename-too-long-infra`, `runner-arch-mismatch-infra`, `docker-layer-cache-missing-infra`, `java-heap-oom-infra`, `python-memory-error-infra`, `bazel-remote-cache-unavailable-infra`, `nix-nar-hash-mismatch-infra`, `homebrew-bottle-download-infra`, `apt-mirror-404-infra`, `rust-linker-oom-infra` |
| `unknown` | No signal clears the threshold, a bare cancel, a concurrency cancel, or two categories tie | You want the report to sound decisive | `bare-exit-unknown`, `canceled-step-unknown`, `timeout-and-assertion-unknown`, `empty-token-and-permission-unknown`, `force-push-refusal-only-unknown`, `cache-eacces-unknown`, `concurrency-cancel-unknown`, `poetry-lock-and-assertion-unknown`, `oom-and-permission-unknown`, `oidc-role-and-empty-arn-unknown`, `shard-retry-only-unknown`, `checkout-tls-and-assertion-unknown`, `dataset-and-assertion-unknown`, `egress-and-permission-unknown`, `checkout-hook-only-unknown`, `multi-job-green-noise-unknown`, `registry-auth-and-egress-unknown`, `healthcheck-and-assertion-unknown`, `cache-eacces-and-lockfile-unknown`, `registry-rate-and-auth-unknown`, `econnreset-and-assertion-unknown` |

If `alternates` is non-empty or confidence is not `high`, say which other category was close and which lines you used. Stay inside this list.
