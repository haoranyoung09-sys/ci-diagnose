# Taxonomy v0 (skill reference)

Ids: `flake`, `env`, `test`, `deps`, `permissions`, `infra`, `unknown`.

The CLI in `scripts/diagnose.py` is the smoke oracle. It scores the signals below, picks the leader when the score is at least 6, and returns `unknown` under that threshold or on a tie. If you edit a signal here, edit the rule and [docs/taxonomy.md](../../../docs/taxonomy.md) in the same change. When the full repo is not on disk, this file is enough to classify by hand.

Confidence from the CLI: `high` (≥ 0.80), `medium` (≥ 0.60), `low`. Repeat that level. Do not round it up to a merge decision.

| id | Pick it when | Do not pick it when | Fixture |
| --- | --- | --- | --- |
| `flake` | Timeout, "timeout of N ms exceeded", "suspected flake", passed on rerun, intermittent, retry N of M | The assertion fails the same way every time, or it ties with `AssertionError`. A shard that only says "retry N of M" is under the threshold | `jest-timeout-flake`, `registry-timeout-rerun-flake`, `playwright-timeout-flake`, `cypress-timeout-flake`, `matrix-shard-flake`, `docker-rate-limit-flake` |
| `env` | A named variable, action input, or secret name is unset or empty, including a Compose `DATABASE_URL` | The token is present and GitHub returned 403, or the empty name ties with "does not have permission" | `missing-database-url`, `missing-node-auth-token`, `unset-api-base-url`, `secret-signing-key-missing`, `aws-region-undefined`, `compose-db-url-unset` |
| `test` | `FAIL` / `FAILED`, `--- FAIL:`, `AssertionError`, PHPUnit "Failed asserting that", RSpec `Failure/Error:`, cargo `test result: FAILED`, Gradle `AssertionError` | The suite never started, a timeout that passed on rerun, or a tie with that timeout or with a lockfile | `npm-test-assertion`, `pytest-assertion`, `go-test-want-got`, `maven-surefire-assertion`, `phpunit-assert-failed`, `rspec-failure-error`, `cargo-test-result-failed`, `gradle-test-assertion` |
| `deps` | `ERESOLVE`, peer conflict, npm, pnpm, yarn, poetry, or uv lockfile drift, pip unsatisfied, Gradle unresolved configuration | `NODE_AUTH_TOKEN` is simply empty, or the lockfile ties with `AssertionError` | `npm-peer-eresolve`, `npm-ci-lockfile-drift`, `pnpm-outdated-lockfile`, `pip-version-unsatisfied`, `yarn-lockfile-out-of-date`, `poetry-lock-out-of-date`, `uv-lock-needs-update`, `gradle-configuration-unresolved` |
| `permissions` | Integration 403, `HttpError` 403, `permissions:` or `id-token:` not granted, remote rejected the push, OIDC assume-role blocked on `id-token: write` | A secret value was never provided, a filesystem `EACCES`, only "Refusing to force-push", or an empty role ARN tied with "does not have permission" | `gha-token-integration-403`, `git-push-permission-denied`, `id-token-permission-denied`, `bare-http-403`, `oidc-assume-role-denied` |
| `infra` | Heap OOM, generic "out of memory", disk full, runner killed, Docker daemon unreachable, Docker build disk full | A flaky timeout that passed on rerun, `EACCES` on a cache directory with no host line, or OOM tied with a permission line | `node-heap-oom`, `runner-disk-full`, `generic-oom-without-heap`, `runner-killed-exit-137`, `docker-build-disk-full`, `docker-daemon-unavailable` |
| `unknown` | No signal clears the threshold, a bare cancel, a concurrency cancel, or two categories tie | You want the report to sound decisive | `bare-exit-unknown`, `canceled-step-unknown`, `timeout-and-assertion-unknown`, `empty-token-and-permission-unknown`, `force-push-refusal-only-unknown`, `cache-eacces-unknown`, `concurrency-cancel-unknown`, `poetry-lock-and-assertion-unknown`, `oom-and-permission-unknown`, `oidc-role-and-empty-arn-unknown`, `shard-retry-only-unknown` |

If `alternates` is non-empty or confidence is not `high`, say which other category was close and which lines you used. Stay inside this list.
